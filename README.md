# Project Reports

Plain-English reports on my GitHub projects. Each folder has the same nine files: system design, a whiteboard guide, a LinkedIn post, a blog post, two explainers (non-technical and technical), interview prep, ten key facts, and the skills the project shows.

Everything here is based on what each repo's code actually shows. Where something isn't measured in a repo, the report says so.
