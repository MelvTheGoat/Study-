I built a tool that lets AI assistants check whether a crypto token or wallet is risky. It looks for scams like tokens you can't sell or hidden owner powers, and gives a risk score from 0 to 100 with a reason for every point. It only reads data, so it can never move money. There's now a live web page for Arc, Circle's blockchain, that checks an address before you send USDC: https://arc-safe-send.onrender.com
